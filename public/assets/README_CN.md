# 资源文件说明

## `main.pdf`

`main.pdf` 是本站当前使用的简历 PDF。

这个文件在需要时可以保存在 Git 中，但不要把它当作普通文本文件处理：

- 它是二进制文件
- 即使只是很小的简历改动，通常也会导致整个文件的字节内容变化
- Git 无法为它提供有意义的逐行 diff
- 反复更新会让仓库体积不必要地增长

## 更新规则

当新的简历版本需要替换 `main.pdf` 时，不要只是直接覆盖后正常提交。

请使用这个规则：

1. 先从 Git cache/index 中移除旧的 `main.pdf`
2. 再把新的 `main.pdf` 作为新版本加入
3. 然后提交这次替换

这样做的目的是避免把不断变化的二进制简历文件当作普通源码文件处理。
