# 资源文件说明

## 当前简历 PDF

本站当前公开使用的简历 PDF 是：

`resume-august-24-2026.pdf`

这是 August 24, 2026 版本的简历 PDF。

简历 PDF 是二进制文件。Git 无法为它提供有意义的逐行 diff，反复更新二进制文件也会让仓库体积不必要地增长。

## 更新规则

发布新简历时，新增一个带日期的 PDF 文件，不再复用模糊的通用文件名。

命名格式使用：

`resume-month-dd-yyyy.pdf`

然后修改仓库相对路径 `src/data/siteLinks.ts`，把其中的简历链接更新为新的日期版 PDF 相对路径。

旧简历 PDF 不得继续留在 Git 历史中。发布新版本时，必须按精确路径从所有受影响的分支和标签历史中清除旧文件，然后强制更新对应的远程引用，避免二进制文件持续增加仓库体积。

这一流程会改写提交哈希和远程历史，执行前必须明确确认清除路径、受影响的分支与标签，并通知其他协作者重新同步或克隆仓库。任何 force push 执行前都必须再次询问用户并取得明确确认，不得自动沿用以前的授权。
